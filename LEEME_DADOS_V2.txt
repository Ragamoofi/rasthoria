QUÉ CAMBIÓ
----------
- Se eliminó del juego el experimento visual anterior de dados.
- Nueva tirada cinemática a pantalla completa.
- D4, D6, D8, D10, D12, D20 y D100.
- Los números están físicamente pegados a las caras del dado.
- El resultado del motor se calcula primero y el dado visual termina mostrando ESA cara.
  El sistema visual no altera el azar ni las reglas.
- Rebotes, desplazamiento, giro, choques aproximados, sombras e iluminación.
- Sonido corto de dados generado por el navegador, con botón para silenciarlo.
- Ventaja/desventaja muestra dos D20 y al final atenúa el descartado.
- D100 se representa como dos D10 (decenas + unidades).
- 20 natural tiene presentación especial.
- Se eliminó visualmente el antiguo "..." mientras se espera el resultado.
