Política de privacidad de RASTHOR·IA

Última actualización: 22 de septiembre de 2026

RASTHOR·IA es un RPG narrativo que puede funcionar como plugin/app de ChatGPT mediante un servidor MCP. En esa modalidad, ChatGPT actúa como Narrador y RASTHOR·IA aporta herramientas mecánicas como ficha, dados, puntos de golpe, inventario y estado de escena.

Datos que procesa

Las herramientas MCP reciben únicamente los datos de partida necesarios para ejecutar la acción solicitada, por ejemplo la ficha del personaje, estado de campaña, tiradas o cambios de inventario. El servidor MCP de RASTHOR·IA está diseñado como servicio sin estado: no crea cuentas propias ni guarda de forma persistente las campañas recibidas por las herramientas.

Claves y credenciales

La ChatGPT Edition no solicita ni almacena claves API de OpenAI, Gemini u otros proveedores. La narración la realiza ChatGPT en la conversación del usuario.

Registros técnicos

El alojamiento puede generar registros técnicos y metadatos operativos necesarios para seguridad, diagnóstico y disponibilidad. RASTHOR·IA no incorpora publicidad ni vende datos personales.

Terceros

El uso dentro de ChatGPT también está sujeto a las políticas y controles de OpenAI. El alojamiento técnico del endpoint MCP utiliza Cloudflare Workers.

Contacto

Para consultas de privacidad o soporte, utiliza el repositorio oficial de RASTHOR·IA: github.com/Ragamoofi/rasthoria.
