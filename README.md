# RASTHOR·IA

**Tu historia aún no ha sido escrita.**

RPG narrativo dinámico dirigido por IA, con motor de dados, campañas libres y consecuencias persistentes.

## Estructura

- `index.html` — juego web.
- `ai-worker.js` — respaldo local experimental.
- `cloudflare-worker/` — backend del Dungeon Master en la nube mediante Cloudflare Workers AI.

El proyecto RASTHOR·IA es completamente independiente de PokéSenda.
